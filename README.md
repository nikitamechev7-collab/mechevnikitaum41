# Формування Kanban дошки

## Опис проєкту
Даний проєкт присвячений формуванню та використанню Kanban-дошки для управління процесом виконання завдань у GitHub.  
Kanban-дошка використовується для візуалізації етапів роботи, контролю статусів задач та фіналізації результатів.

## Мета роботи
Навчитися створювати та використовувати Kanban-дошку в GitHub Projects для управління проєктною діяльністю.

## Завдання проєкту
1. Написання технічного завдання  
2. Формування датасету  
3. Вибір та запуск моделі  
4. Вибір та оцінка метрик  
5. Формування звіту з результатами  

## Kanban-дошка
Для керування проєктом використовується Kanban-дошка з такими колонками:
- Backlog  
- ToDo  
- In Progress  
- For Review  
- Done
